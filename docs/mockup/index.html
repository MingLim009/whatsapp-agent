Flujos del bot

Los tres momentos clave del ciclo de vida de una operación.

1
Plantilla Meta

Operación creada

El cliente genera una orden en la web Odoo. El sistema envía automáticamente:

“Generaste una operación en nuestra web. Ya estamos trabajando en ella.”
Odoo crea operación→ Encola mensaje→ Kommo → WhatsApp
2
Plantilla o Claude

Operación concluida

Al cargar el voucher y pasar a estado “concluida”:

Ventana cerrada

Plantilla Meta de cierre:

“Tu orden ya fue concluida. Revisa tu correo para obtener el voucher.”
Ventana abierta (24 h)

Claude redacta cierre personalizado con contexto de la operación.

3
Claude dinámico

Cliente responde

Kommo notifica a Odoo vía webhook. El bot responde con contexto + historial.

WhatsApp entrante→ Webhook Odoo→ Claude→ Envío Kommo
